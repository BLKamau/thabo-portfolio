# The Systems Dispatch — Interim Portfolio

This a minimal, tech-newspaper-styled personal portfolio I built with React + Vite.

## Running locally

    npm install
    npm run dev

Then open the printed localhost URL.

## Building for production

    npm run build

## Structure

    src/
      components/       one component + one .module.css per section
      data/              all editable content, separate from layout
      styles/
        tokens.css       color / type / spacing variables - the whole palette
        global.css       resets + base typography
